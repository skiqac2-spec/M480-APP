M480Tube - SCH-M480(Windows Mobile 6.1)용 유튜브 뷰어
=====================================================

[설치]
- M480Tube.cab 을 누르면 설치되고 시작 메뉴(프로그램)에 M480Tube 가 생깁니다.
- 설치 없이 쓰려면 M480Tube.exe 를 아무 폴더에 넣고 실행해도 됩니다.
- Wi-Fi 연결을 권장합니다 (240p 영상 + 소리 = 약 1분에 2~3MB).

[사용법]
- 위쪽 칸에 검색어를 쓰고 [검색] (또는 확인 버튼).
- 목록은 손가락으로 위아래로 끌어서 스크롤. 맨 아래까지 내리면 결과를 더 불러옵니다.
- 영상을 누르면 재생 화면으로 바뀝니다.

[재생 화면]
- 기본은 가로 전체화면. 화면을 한 번 누르면 조작 막대가 나오고, 4초 뒤 사라집니다.
- [< 목록] 목록으로 돌아가기      [회전] 가로(왼쪽) → 가로(오른쪽) → 세로 순서로 바뀜
- [-10초] [재생/일시정지] [+10초]
- 빨간 진행 막대를 누르거나 끌면 그 위치로 이동
- 하드웨어 버튼: 좌/우 = 10초 이동, 확인 = 재생/일시정지, 뒤로 = 목록
- 오른쪽 위에 "240p 20fps" 처럼 실제 화질과 초당 프레임이 표시됩니다.

[메뉴 (오른쪽 위 세 줄 버튼)]
- 화질: 240p(기본) / 144p(빠름) / 360p(느릴 수 있음)
  영상이 뚝뚝 끊기면 144p 로 바꿔 보세요. 240p가 없는 영상은 144p로 나옵니다.
- 재생 화면: 세로 / 가로
- 유튜브 연결 설정 다시 받기: 유튜브가 바뀌어 재생이 안 될 때 눌러 보세요.
  (앱이 켜질 때마다 자동으로 최신 설정을 받습니다)

[소리]
- 이어폰에서 찌그러지지 않도록 22kHz, 60% 음량, 초저음 컷으로 출력합니다
  (M480Music 과 같은 방식). 음량은 기기 볼륨 버튼으로 조절하세요.

[문제가 생기면]
- 프로그램 폴더의 m480tube_log.txt 에 마지막 실행 기록이 남습니다.
  재생이 안 되면 이 파일 내용을 알려 주세요.
- 실시간 방송, 회원 전용, 연령 제한(로그인 필요) 영상은 재생되지 않습니다.
