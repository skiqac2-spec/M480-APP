M480Tube - SCH-M480(Windows Mobile 6.1)용 유튜브 뷰어
=====================================================

[설치]
- M480Tube.cab 을 누르면 설치되고 시작 메뉴(프로그램)에 M480Tube 가 생깁니다.
- 설치 없이 쓰려면 M480Tube.exe 를 아무 폴더에 넣고 실행해도 됩니다.
- Wi-Fi 연결을 권장합니다 (240p 영상 + 소리 = 약 1분에 2~3MB).

[사용법]
- 위쪽 칸에 검색어를 쓰고 [검색] (또는 확인 버튼).
- 목록은 손가락으로 위아래로 끌어서 스크롤. 맨 아래까지 내리면 결과를 더 불러옵니다.
- 영상을 누르면 재생 화면으로 바뀝니다.

[탭 / 기록 / 채널 / 구독]
- 검색창 아래 [기록] [검색] [구독] 탭이 있습니다.
- [기록]: 최근 본 영상이 본 순서대로 나옵니다. 앱을 켜면 이 탭부터 보입니다.
  영상을 길게 누르면 '기록에서 삭제', 메뉴에서 '시청 기록 모두 지우기'를 할 수 있습니다.
  (기록은 이 폰의 M480Tube 폴더 m480tube_history.txt 에 최대 200개 저장)
- 영상의 채널 이름(제목 아래 회색 글씨)을 누르면 그 채널의 영상 목록이 열립니다.
  영상을 길게 눌러도 '재생 / 채널 보기 / 채널 구독' 메뉴가 나옵니다.
- 채널 화면 오른쪽 위 [구독]을 누르면 구독됩니다. [< 뒤로]로 돌아갑니다.
- [구독] 탭: 구독한 채널들의 새 영상을 최신순으로 모아 보여 줍니다. [새로고침]으로 다시 받습니다.
  지난번 피드를 저장해 두었다가 바로 보여 주고, 새 영상만 받아서 끼워 넣습니다.
  (15분 안에 받은 채널은 건너뜁니다 - 유튜브도 15분마다 갱신)
- 지금 보고 있는 탭을 한 번 더 누르면 목록 맨 위로 올라갑니다. (채널 화면은 채널 이름을 누르면)
- 구독은 유튜브 계정이 아니라 이 폰에 저장됩니다 (M480Tube 폴더의 m480tube_subs.txt).
- 유튜브 계정의 구독 목록 옮기기:
  1) PC에서 takeout.google.com 접속 > 'YouTube 및 YouTube Music'만 선택 > 포함할 데이터에서 '구독정보'만 선택 > 내보내기
  2) 받은 압축파일 안의 구독정보 .csv 파일을 폰 아무 곳(메모리 카드 포함)에 복사
     (파일 이름은 달라도 됩니다)
  3) 메뉴 > '구독 목록 가져오기'
     가져온 채널은 처음엔 피드에 들어가지 않습니다. 이어서 '구독 관리' 화면이 열리면
     영상을 받아 볼 채널만 체크하세요.
- 구독 관리: [구독] 탭 오른쪽 위 [관리] (또는 메뉴 > '구독 관리')
  체크한 채널의 새 영상만 [구독] 탭에 나옵니다. 줄을 누르면 체크/해제,
  [전체 선택]/[전체 해제], 길게 누르면 '채널 보기 / 구독 취소'. [완료]로 저장합니다.
  (새로 구독한 채널은 자동으로 체크됩니다)

[채널 화면]
- 채널 이름 아래 [동영상] / [지난 라이브] 탭이 있습니다.
  [지난 라이브]는 끝난 실시간 방송(다시보기)만 보여 주고, 지금 방송 중이거나 예정된 방송은 뺍니다.
- 오른쪽 [정렬]로 채널 영상도 최신순/조회수순 등으로 볼 수 있습니다.

[이어서 보기]
- 영상을 보다 나가면 어디까지 봤는지 기억합니다 (재생 중에도 30초마다 저장).
  다음에 같은 영상을 누르면 그 위치 3초 전부터 이어서 재생하고 '... 부터 이어서 재생'이 잠깐 뜹니다.
- 본 위치는 목록의 썸네일 아래 빨간 막대로 보입니다.
- 처음부터 보려면 영상을 길게 눌러 '처음부터 재생'.
- 끝까지 본 영상(끝 15초 이내)과 10초도 안 본 영상은 기억하지 않습니다. 최근 300개까지 저장.

[스크롤 손잡이]
- 목록 오른쪽 끝의 회색 손잡이(▲▼)를 잡고 위아래로 끌면 영상을 건드리지 않고 스크롤됩니다.
  손잡이 위/아래 빈 곳을 누르면 그 위치로 바로 이동합니다.
- 손가락으로 목록을 끌 때 조금만 움직여도 '스크롤'로 처리하고,
  미끄러지던 목록을 멈추려고 누른 터치로는 영상이 열리지 않습니다.

[정렬]
- 탭 줄 오른쪽 [정렬] 버튼: 기본순 / 최신순 / 오래된순 / 길이 긴순 / 길이 짧은순 / 조회수 많은순
  탭(기록·검색·구독)과 채널 화면마다 따로 정해집니다. 정렬 중이면 버튼이 '정렬*'로 표시됩니다.
  검색 결과는 지금까지 불러온 영상 안에서 정렬됩니다 (더 불러오면 다시 정렬).

[화면 설정] 메뉴 > 화면
- 목록으로 보기 / 격자로 보기(2칸)
- 다크 모드

[재생 화면]
- 재생 중에 전원 버튼으로 화면을 끄면 소리만 계속 나옵니다 (M480Music 과 같은 방식).
  화면이 꺼져 있는 동안은 영상 받기/풀기를 멈춰 배터리를 아끼고,
  화면을 다시 켜면 영상이 소리 위치로 따라옵니다. 일시정지하면 평소처럼 폰이 잠듭니다.
- 영상을 보는 동안에는 화면이 저절로 꺼지지 않습니다.
- 기본은 가로 전체화면. 화면을 한 번 누르면 조작 막대가 나오고, 4초 뒤 사라집니다.
- 쇼츠 같은 세로 영상은 자동으로 세로 비율 그대로 화면 가득 나옵니다.
- [비율]/[채움] 버튼(또는 휴대폰의 소프트키): 원본 비율 <-> 화면 꽉 채우기(가장자리 잘림) 전환
- [< 목록] 목록으로 돌아가기      [회전] 가로(왼쪽) → 가로(오른쪽) → 세로 순서로 바뀜
- [-10초] [재생/일시정지] [+10초]
- 빨간 진행 막대를 누르거나 끌면 그 위치로 이동
- 하드웨어 버튼: 좌/우 = 10초 이동, 확인 = 재생/일시정지, 뒤로 = 목록
- 오른쪽 위에 "240p 20fps" 처럼 실제 화질과 초당 프레임이 표시됩니다.

[메뉴 (오른쪽 위 세 줄 버튼)]
- 화면: 목록/격자, 다크 모드, 재생 화면 방향, 초당 프레임 표시
- 화질: 240p(기본) / 144p(빠름) / 360p(느릴 수 있음)
  영상이 뚝뚝 끊기면 144p 로 바꿔 보세요. 240p가 없는 영상은 144p로 나옵니다.
- 유튜브 연결 설정 다시 받기: 유튜브가 바뀌어 재생이 안 될 때 눌러 보세요.
  (앱이 켜질 때마다 자동으로 최신 설정을 받습니다)

[소리]
- 이어폰에서 찌그러지지 않도록 22kHz, 60% 음량, 초저음 컷으로 출력합니다
  (M480Music 과 같은 방식). 음량은 기기 볼륨 버튼으로 조절하세요.

[문제가 생기면]
- 프로그램 폴더의 m480tube_log.txt 에 마지막 실행 기록이 남습니다.
  재생이 안 되면 이 파일 내용을 알려 주세요.
- 실시간 방송, 회원 전용, 연령 제한(로그인 필요) 영상은 재생되지 않습니다.
