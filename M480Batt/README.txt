M480 배터리 진단 1.1
====================

"전원 버튼을 누르면 가끔 바로 꺼지는" 원인을 가려내는 앱입니다.
켜 둔 채로 평소처럼 쓰다가 기기가 갑자기 꺼지면, 다시 켜서 이 앱을 열었을 때
꺼지기 직전 상태를 보고 원인을 알려 줍니다.


쓰는 순서
---------
1. 설치하고 "M480 Battery"를 실행합니다.
2. 아래 [자동 꺼짐] 단추를 눌러 [자동 켜짐]으로 바꿉니다.
   (기기를 켤 때마다 화면 없이 자동으로 기록을 시작합니다. 강력 추천)
3. [숨기기]를 누르고 평소처럼 씁니다. 기록은 숨긴 채로 계속됩니다.
   ([종료]를 누르면 기록이 멈춥니다.)
4. 기기가 갑자기 꺼지면 다시 켠 뒤 앱을 엽니다.
   "방금 갑자기 꺼졌습니다"와 함께 판정 결과가 나옵니다.
5. 두세 번 꺼질 때까지 모아 보면 더 확실합니다. [기록]에서 전부 볼 수 있습니다.


화면 보는 법
------------
- 위 카드: 지금 잔량, 전압, 쓰는 전류, 온도
  · 전압이 3.55V보다 낮으면 빨간색으로 나옵니다.
  · "깨울 때 하락": 전원 버튼으로 깨울 때 전압이 얼마나 떨어졌는지.
    250mV(0.25V) 넘게 떨어지면 노란색 = 배터리가 낡았다는 신호.
- 그래프: 최근 30분 전압. 빨간 가로선이 3.55V, 주황 점이 깨어난 순간.
- 아래 카드: 판정 결과 (누르면 기록 화면)


판정 결과 뜻
------------
- 꺼지기 직전 전압이 낮았음        → 배터리 노화. 교체하세요.
- 깨어나는 순간 / 화면 꺼진 상태에서 꺼짐 → 배터리 노화 또는 배터리 접점 문제.
  접점을 지우개나 알코올로 닦아 보고, 그래도 반복되면 배터리 교체.
- 충전기를 꽂은 채 꺼짐            → 배터리보다 전원 버튼이나 기기 쪽 문제.
- 잔량이 남았는데 꺼짐(전압 모름)    → 배터리 노화 가능성 높음.

※ 배터리 칩이 전압을 몇 초에 한 번만 갱신하면 아주 짧은 순간 하락은
  못 잡을 수 있습니다. 그래도 "꺼지기 직전 상태"와 "충전기 연결 여부"만으로
  배터리 탓인지 기기 탓인지는 대부분 구분됩니다.
※ 가장 빠른 확인법: 충전기를 꽂은 채로 며칠 써 보세요.
  그때는 안 꺼진다면 거의 확실히 배터리 문제입니다.


키
--
왼쪽 소프트키 = 기록 보기 / 오른쪽 소프트키 = 숨기기 / 위·아래 = 기록 화면 넘기기


기록 파일
---------
앱 폴더(\Program Files\M480Batt)의 M480Batt_log.csv
PC에서 엑셀로 열 수 있습니다. 칸 순서:
  시각, 틱(ms), 종류, 잔량%, 전압mV, 전류mA, 온도(0.1도), 충전기(1=연결)
종류: S=10초마다, W=깨어난 직후 측정, SLEEP=잠듦, WAKE=깨어남,
      SCROFF=화면 꺼짐, BLON=화면 켜짐, ACIN/ACOUT=충전기 연결/분리,
      DROP=깨어날 때 하락(추가 칸: 하락 mV, 직전 mV),
      CRASH=갑자기 꺼짐 판정(추가 칸: 판정 번호, 꺼지기 전 마지막 기록 시각),
      START/END=앱 시작/종료
1MB쯤 쌓이면 M480Batt_old.csv로 옮기고 새로 씁니다 (갑자기 꺼짐 기록은 유지).


1.1에서 바뀐 점
---------------
- 화면 아래 가운데 키보드(가) 단추가 [기록]·[숨기기] 단추를 가리던 문제를 고쳤습니다.
  (이 앱이 앞에 있을 때만 키보드 단추를 숨기고, 나가면 다시 보입니다)
- 위에 회색 제목 줄이 한 줄 더 생겨 아래 글이 잘리던 문제를 고쳤습니다.
- [기록] 화면 맨 아래에 기기가 주는 배터리 원래 값을 보여 줍니다.
  "전압 정보 없음"으로 나오면 이 기기는 전압을 알려 주지 않는 것이라,
  꺼지기 직전 잔량과 충전기 연결 여부로 판정합니다.
