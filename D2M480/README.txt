D2M480 - SCH-M480용 디아블로2 (정품 데이터 사용 이식판)
=========================================================

정품 디아블로2 + 파괴의 군주(1.14d) 데이터를 SCH-M480(윈도우 모바일 6.1)에 맞게
줄여서(320x240 화면, 그림 1/2 크기, 11~22kHz 모노 소리) 새 엔진으로 돌리는 프로젝트입니다.
원작 실행 파일은 쓰지 않고, 그림·소리·수치표 같은 데이터만 정품에서 가져옵니다.

진행 단계
---------
 1단계 (지금) : PC용 데이터 변환기  ............ 완료
 2단계        : M480용 엔진 - 직업 선택 화면, 로그 캠프, 블러드 무어 이동
 3단계        : 바바리안 스킬·전투, 액트1 끝(안다리엘)까지
 4단계        : 나머지 직업 팩·액트 팩

1단계: 데이터 변환기 사용법 (PC에서)
------------------------------------
1. converter/D2M480_Converter.html 파일을 PC에 받아서 더블클릭합니다.
   (크롬, 엣지, 사파리 등 아무 브라우저나 됩니다. 인터넷 연결은 필요 없습니다.)
2. 디아블로2 설치 폴더의 .mpq 파일을 모두 골라 넣습니다.
   꼭 필요한 파일: d2data, d2exp, d2char, d2sfx, d2music, patch_d2
3. 만들 팩을 고르고 '변환 시작'을 누릅니다. 몇 분 걸립니다.
4. 저장된 .pak 파일들을 휴대폰 SD카드의 D2M480 폴더에 넣습니다.
     d2_common.pak  - 수치표, 문자열, 팔레트, UI, 아이템 그림, 공용 효과음
     d2_act1.pak    - 액트1 맵 타일, 맵 조각, 몬스터·NPC·오브젝트, 음악
     d2_ba.pak      - 바바리안 그림(장비별), 스킬 이펙트, 목소리, 스킬 아이콘

* 모든 변환은 PC 안에서만 이루어지며 파일이 인터넷으로 나가지 않습니다.
* 만들어진 .pak 파일은 정품 데이터로 만든 것이므로 다른 사람에게 나눠 주거나
  인터넷(이 저장소 포함)에 올리지 마세요. 이 저장소에는 엔진과 변환기만 올립니다.

팩 파일 구조 (엔진 개발용 메모)
-------------------------------
PAK  : 'D2PK' u32 버전(1), u32 항목 수, u32 목록 위치 / 데이터 /
       목록: [u32 위치, u32 크기, u8 이름길이, 이름(소문자, '/' 구분)] 이름순 정렬
       이름은 원본 경로 그대로 (예: data/global/chars/ba/hd/bahdlitnuhth.dcc)
SPR1 : DC6/DCC를 1/2로 줄인 그림. 'SPR1' u16 방향 수, u16 방향당 프레임 수,
       프레임마다 [i16 왼쪽, i16 위, u16 폭, u16 높이, u32 데이터 위치],
       데이터는 위→아래 행 단위: 0x80=행 끝, 0x80|n=투명 n칸, n(1~127)=픽셀 n개(팔레트 번호)
TIL1 : DT1 타일 묶음. 'TIL1' u32 개수, 타일마다 48바이트
       [i32 방향, i16 지붕높이(1/2), u16 재질, i32 종류, i32 스타일, i32 순번, i32 희귀도, u8 하위칸[25], 여유 3],
       이어서 SPR1 하나(방향 1, 프레임=타일 수)에 모든 타일 그림
ADP1 : 소리. 'ADP1' u32 샘플레이트, u32 샘플 수, u16 블록 샘플(1024), u16 0,
       블록마다 [i16 첫 샘플, u8 스텝 번호, u8 0, 4비트 IMA ADPCM 코드(아래 니블 먼저)]
그 밖에 COF, DS1, 수치표(.txt), 문자열(.tbl), 팔레트(pal.dat, pal.pl2), animdata.d2는 원본 그대로.

변환기 소스
-----------
converter/js/compress.js  MPQ 압축 해제 (PKWARE, 허프만, ADPCM, zlib)
converter/js/mpq.js       MPQ 읽기
converter/js/gfx.js       팔레트·DC6·DCC·DT1 해독, 1/2 축소, SPR1/TIL1 인코딩
converter/js/sound.js     WAV → ADP1
converter/js/pack.js      수치표 읽기, COF 해석, PAK 쓰기
converter/js/builder.js   팩 구성 (어떤 파일을 어느 팩에 넣을지)
converter/data/obj.txt    맵 배치 번호 → 유닛 토큰 표 (게임 MPQ에 없어서 내장)
tools/build_converter.py  위 파일들을 converter/D2M480_Converter.html 하나로 합침

참고: 압축 해제는 StormLib(Ladislav Zezula), DCC 해독 순서와 obj.txt 표는
OpenDiablo2 프로젝트를 참고했습니다.
