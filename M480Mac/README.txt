M480Mac 1.0 - SCH-M480용 매킨토시 에뮬레이터 (맥 OS 7.5 컬러)
================================================================

Mac II(640x480, 256색)를 흉내 내서 맥 OS 7.5를 컬러로 돌립니다.
맥 화면 전체를 절반 크기(320x240)로 줄여 M480 화면 위쪽에 보여 주고,
아래쪽에는 터치 버튼 8개가 있습니다.
(줄일 때 2x2 점을 섞되 어두운 점 쪽으로 살짝 치우치게 해서
 얇은 선과 글자가 사라지지 않게 했습니다.)


■ 준비물 (저작권 때문에 함께 넣을 수 없는 파일)

 1) Mac II ROM 파일
    - 파일 이름: MacII.ROM  (크기 256KB)
    - 실물 Mac II에서 뽑은 ROM이어야 합니다.
 2) 맥 OS 7.5가 설치된 디스크 이미지
    - 가장 쉬운 방법: PC에서 Mini vMac(Mac II 판)으로 시스템 7.5가
      설치된 하드디스크 이미지를 만든 뒤 그 파일을 가져오기
    - 파일 이름을 disk1.dsk 로 바꾸면 켤 때 자동으로 넣어지고
      그 디스크로 부팅합니다.
      (disk2.dsk ... disk9.dsk 도 차례로 자동으로 넣어집니다)
    - 애플이 예전에 무료로 배포한 시스템 7.5.3 설치 디스크 이미지로
      직접 설치해도 됩니다.


■ 파일 넣는 곳

  저장 카드\M480Mac\          <- 여기를 권장 (폴더를 직접 만드세요)
     MacII.ROM
     disk1.dsk      (부팅 디스크)
     disks\        (그 밖의 디스크 이미지, 있어도 되고 없어도 됨)

  설치 폴더(\Program Files\M480Mac)에 넣어도 됩니다.
  디스크 이미지는 크기가 커서 저장 카드에 두는 것이 좋습니다.


■ 처음 켜면

  - ROM이 없으면 맥 화면에 "Unable to locate ROM image" 같은
    영어 안내가 나옵니다. [디스크] 버튼으로 MacII.ROM을 고르면
    바로 읽어 들입니다.
  - 부팅 디스크가 없으면 물음표 디스크 그림이 깜빡입니다.
    [디스크] 버튼으로 시스템 디스크 이미지를 넣으세요.

  ★ 컬러로 보려면 (처음 한 번)
    맥 화면 왼쪽 위 사과 메뉴 > Control Panels > Monitors 에서
    [256]을 고르세요. 다음부터는 계속 컬러로 켜집니다.


■ 조작

  맥 화면 누르기       : 그 자리로 마우스를 옮기고 클릭
  누른 채로 끌기       : 드래그 (메뉴 열기, 창 옮기기, 아이콘 끌기)
  빠르게 두 번 누르기  : 더블클릭 (프로그램·폴더 열기)
  M480 쿼티 키보드     : 맥 키보드로 그대로 입력 (영문)

  아래 버튼
   [디스크]  디스크 이미지 고르기 (저장 카드\M480Mac, disks 폴더,
             설치 폴더를 찾아 목록으로 보여 줌, 누르면 넣어짐)
   [키보드]  화면 키보드 켜기/끄기
   [커맨드]  맥 커맨드(⌘) 키
   [옵션]    맥 옵션 키
   [시프트]  시프트 키
   [컨트롤]  컨트롤 키
             - 누르면 '켜짐'으로 바뀌고, 그 상태에서 키보드 글쇠를 한 번
               누르면 같이 눌린 것으로 들어간 뒤 자동으로 꺼집니다.
               예) [커맨드] 누르고 Q  ->  커맨드-Q (프로그램 끝내기)
             - 클릭과 함께 쓰려면 켜 둔 채로 화면을 누르고,
               다 쓰면 버튼을 다시 눌러 끄세요. (예: 시프트-클릭)
   [속도]    1배 -> 2배 -> 4배 -> 최대 -> 1배 ... 차례로 바뀜
             M480이 따라가지 못하면 '최대'와 같은 속도로 돌아갑니다.
   [종료]    에뮬레이터 끄기. 디스크가 들어 있으면 한 번 더 묻습니다.


■ 끌 때 주의

  디스크 이미지가 망가지지 않도록, 끄기 전에 맥에서
  Special 메뉴 > Shut Down 을 하세요. 맥이 꺼지면 프로그램도
  자동으로 닫힙니다.


■ 사양

  기종: Macintosh II (68020 + FPU), 메모리 8MB
  화면: 640x480 256색 (흑백도 가능) -> 320x240으로 축소 표시
  소리: 있음
  디스크: 플로피·하드디스크 이미지 (.dsk .img .image .hfv .hda .dc42 등)
