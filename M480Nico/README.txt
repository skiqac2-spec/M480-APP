M480Nico 0.1 테스트판 - SCH-M480(Windows Mobile 6.1)용 니코니코 동화 뷰어
=====================================================================

M480Tube(유튜브 뷰어)를 바탕으로 만든 테스트판입니다.
화면 구성과 조작은 M480Tube와 거의 같습니다.

[설치]
- M480Nico.cab 을 누르면 설치되고 시작 메뉴(프로그램)에 M480Nico 가 생깁니다.
- 설치 없이 쓰려면 M480Nico.exe 를 아무 폴더에 넣고 실행해도 됩니다.
- Wi-Fi(핫스팟) 연결을 권장합니다. 기본 화질(144p 정도) + 소리 = 약 1분에 1.5MB.

[사용법]
- 앱을 켜면 [검색] 탭에 24시간 종합 랭킹이 나옵니다.
- 위쪽 칸에 검색어를 쓰고 [검색]. 검색어를 비우고 [검색]을 누르면 다시 랭킹.
- 일본어 입력: 검색창 오른쪽 [A] 버튼 -> [あ] (M480Tube와 같음, 로마자로 치면 히라가나)
- 영상을 누르면 재생됩니다. 투고자 이름(제목 아래 회색 글씨)을 누르면 투고자 페이지.
- 투고자 페이지: [최신] / [인기] 탭, 오른쪽 위 [구독]으로 팔로우 (이 폰에만 저장).
- [구독] 탭: 팔로우한 투고자들의 새 영상을 모아 보여 줍니다.
- [기록] 탭: 최근 본 영상. 보다 나간 영상은 이어서 재생됩니다.
- 화질은 메뉴에서 바꿀 수 있습니다 (240p 메뉴 = 144p~240p 중 가까운 것, 360p는 M480에서 느릴 수 있음).

[테스트판에서 아직 안 되는 것]
- 코멘트(탄막) 표시
- 니코니코 계정 로그인 / 계정 팔로우 목록 가져오기
- 동영상 필터(정렬·길이·NG 단어)
- 유료·프리미엄 전용·일본 국내 전용 영상은 재생되지 않습니다 (사유가 화면에 나옵니다).

[문제가 생기면]
- 같은 폴더의 m480nico_log.txt 를 보내 주세요.
- "영상 서버가 접근을 거부함 (HTTP 403)": 재생 정보가 만료된 것이니 영상을 다시 열어 보세요.

[참고]
- 니코니코 영상은 암호화되어 전송되며, 이 앱은 공식 앱이 아닌 곳에서 그 암호를 풀어 재생합니다.
  니코니코 이용약관에 어긋나고 일본 저작권법상 문제가 될 수 있으니 개인 테스트 용도로만 쓰세요.
