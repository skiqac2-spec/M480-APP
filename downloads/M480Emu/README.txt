게임 에뮬레이터 모음 for 삼성 SCH-M480 (Windows Mobile 6.1)
==========================================================

하나의 메뉴에서 여러 게임기 게임을 실행합니다.

  되는 게임기                      게임 파일
  -------------------------------  ---------------------------------
  플레이스테이션 (PS1)             .cue+.bin  .img  .iso  .pbp
  게임보이 어드밴스 (GBA)          .gba
  패미컴 (NES)                     .nes
  슈퍼패미컴 (SNES)                .smc  .sfc
  게임보이 / 게임보이 컬러         .gb  .gbc
  메가드라이브 (제네시스)          .md  .gen  .bin
  마스터시스템 / 게임기어          .sms  .gg

  zip으로 압축된 게임도 그대로 됩니다 (PS1 제외).


■ 설치

[방법 1] 설치 파일 (권장)
  M480Emu.cab 를 휴대폰에서 누르면 설치됩니다. (M480Web '내 파일함'에서 받아도 됩니다.)
  설치 위치를 물으면 "Storage Card"(메모리 카드)를 고르세요. 저장 파일이 쌓여도
  본체 공간이 부족해지지 않습니다.
  설치가 끝나면 시작 > 프로그램 에 "M480 Emulator" 가 생깁니다.

[방법 2] 설치 없이
  M480Emu.zip 을 풀어 M480Emu 폴더째 메모리 카드에 복사하고, 그 안의
  Emulator 를 눌러 실행합니다. (폴더 안의 파일을 따로 떼어 놓지 마세요.)

게임 파일은 메모리 카드의 아무 폴더에나 넣으면 됩니다.  예) \Storage Card\Games\
"알 수 없는 게시자" 경고가 나오면 [예]를 누르세요.


■ 쓰는 법

  [게임 고르기]  폴더를 눌러 들어가서 게임을 누르면, 어떤 게임기용인지 알아서
                 판단해 바로 시작합니다. 목록 오른쪽에 게임기 이름이 보입니다.
  [이어하기]     마지막에 하던 게임을 끝낸 그 장면부터 다시 시작합니다.
  [사용 방법]    프로그램 안에서 볼 수 있는 도움말입니다.

  게임 중 화면 아래 [메뉴] 버튼(또는 지우기 키)을 누르면
  저장 / 불러오기 / 설정 / 다른 게임 고르기 / 게임 끝내기 메뉴가 나옵니다.
  설정은 게임기마다 따로 기억됩니다.


■ 기본 키 (쿼티 키보드)

  방향        : 방향키 또는 W A S D
  버튼 4개    : I(위)  J(왼쪽)  K(아래)  L(오른쪽)
  어깨 버튼   : U, O   (PS1은 Y, P 추가)
  START 엔터 / SELECT 스페이스 / 메뉴 지우기(Del)

  게임기별로는 이렇게 됩니다.
    PS1        △ I   □ J   × K   ○ L   L1 U  R1 O  L2 Y  R2 P
    GBA        A = L,  B = K,  L = U,  R = O
    패미컴/GB  A = L,  B = K
    슈퍼패미컴 X = I,  Y = J,  B = K,  A = L,  L = U,  R = O
    메가드라이브 A = J,  B = K,  C = L,  X = U,  Y = I,  Z = O

■ 화면 터치 버튼

  게임 화면 위에 반투명 십자키(왼쪽 아래)와 버튼(오른쪽 아래)이 겹쳐 나옵니다.
   - 누른 채로 손가락/펜을 미끄러뜨리면 방향이 바로 바뀝니다.
   - 두 버튼 사이를 누르면 두 버튼이 같이 눌립니다.
   - 누른 버튼은 파랗게 진해집니다.
  게임 중 [메뉴] > [설정]에서
   - 화면 터치 버튼 : 켬 / 끔
   - 터치 버튼 투명도 : 0%(진하게) · 25%(처음 값) · 50% · 75% · 100%(안 보임, 누르면 동작)
   - 터치 버튼 크기 : 아주 작게 / 작게 / 보통 / 크게 / 아주 크게
   - 십자키 방식 : 대각선 (8방향, 처음 값) / 십자 (4방향)
       대각선: 십자키 사이(작은 점 표시)를 누르면 두 방향이 같이 눌림 - 액션·격투 게임용
       십자  : 항상 상하좌우 중 한 방향만 눌림 - 메뉴·퍼즐·전략 게임에서 오입력 방지
  START·SELECT·L·R 같은 버튼은 지금처럼 화면 맨 아래 줄에 있습니다.
  이 화면은 한 번에 한 곳만 눌리므로, 방향+버튼 동시 입력은 키보드를 함께 쓰세요.
  설정은 게임기마다 따로 기억됩니다.

  키가 맞지 않으면 게임 중 [메뉴] > [설정] > [키 설정]에서 항목을 누르고
  원하는 키를 누르면 바뀝니다. START/SELECT/어깨 버튼은 화면 아래 버튼을
  터치해도 됩니다.


■ 소리 설정

  M480 본체 스피커·유선 이어폰은 44kHz 큰 음량을 받으면 소리가 뭉개지기 때문에
  (M480 뮤직과 같은 이유), 기본값은 22kHz 출력에 음량 여유·초저음 컷·리미터를
  넣어 깨지지 않게 내보냅니다.
  게임 중 [메뉴] > [설정]에서
   - 소리 음질 : 보통 (권장, 22kHz) / 높음 (44kHz, 블루투스 이어폰용)
                 블루투스에서 소리가 안 나거나 잡음이 나면 "높음"으로 바꾸세요.
   - 소리 크기 : 보통 / 작게 / 크게
                 유선 이어폰에서 아직 찌그러지면 "작게"로 바꾸세요.

■ 속도와 소리

  기본값이 이미 속도 우선입니다.
   - 느려지면 자동으로 화면 일부를 건너뛰어 게임 속도를 유지합니다.
   - 그래도 조금 느릴 때는 소리가 끊기는 대신 살짝 낮게(느리게) 들리도록
     맞춰서, 뚝뚝 끊기지 않게 합니다.
  화면 아래 오른쪽 숫자(예: 60.0fps 100%)가 100%에 가까우면 정상 속도입니다.

  더 빠르게 하고 싶으면 [설정]에서
   - 화면 건너뛰기 : [2] 또는 [3]
   - 화면 크게 채우기 : [끔]  (화면은 작아지지만 조금 빨라집니다)
   - 화면 터치 버튼 : [끔] 또는 투명도 100% (아주 조금 빨라집니다)
   - PS1 성능 모드 : [최고속]
   - 마지막 수단으로 소리 [끔]

  이 기기(624MHz)에서 패미컴·게임보이·GBA·슈퍼패미컴·메가드라이브는 대부분
  잘 돌아갈 것으로 예상합니다. PS1은 2D 게임 위주로, 3D 게임은 느릴 수 있습니다.
  슈퍼패미컴의 특수칩 게임(스타폭스, 요시 아일랜드 등)도 느릴 수 있습니다.


■ BIOS (없어도 됩니다)

  모두 BIOS 파일 없이 실행됩니다. 다만 PS1은 실제 BIOS가 있으면 더 많은
  게임이 정상 동작합니다. 본인 소유 기기에서 추출한 파일이 있다면
  M480Emu\bios 폴더에 넣으세요.
    PS1 : scph1001.bin, scph5501.bin, scph7001.bin 등
    GBA : gba_bios.bin


■ 상태 저장 / 불러오기

  게임 중 [메뉴] > [지금 상태 저장] / [저장한 곳에서 다시] 를 누르면 한 번 더 묻습니다.
  잘못 눌러도 진행이 날아가지 않도록:
   - 처음에는 [취소]가 선택되어 있습니다.
   - 창이 뜬 직후(0.4초)의 터치는 무시합니다.
   - 버튼을 누른 채 밖으로 밀어서 떼면 취소됩니다.
  이미 저장된 칸에 저장할 때는 덮어쓴다는 안내가 함께 나옵니다.

■ 저장 파일 위치 (M480Emu 폴더 안)

  saves\<게임기>\   게임 자체의 저장 (배터리 세이브, 메모리 카드)
  states\<게임기>\  [지금 상태 저장], 자동 저장
  temp\             zip에서 꺼낸 게임 1개 (자동으로 정리됨)


■ 문제가 생기면

  - 실행이 안 되거나 "메모리 부족"이 나오면: 다른 프로그램을 모두 끄거나
    휴대폰을 껐다 켠 뒤 다시 실행해 보세요.
  - PS1 게임이 시작되지 않으면: .cue 파일과 .bin 파일이 같은 폴더에 있는지
    확인하세요.
  - 그래도 안 되면 M480Emu 폴더 안의 log_ 로 시작하는 파일
    (log_menu.txt, log_ps1.txt, log_gba.txt ...) 내용을 알려 주세요.


■ 알아 둘 점

  - PSP, 닌텐도64, 닌텐도DS, 세가새턴, 드림캐스트는 이 기기 성능으로는
    불가능해서 넣지 않았습니다.
  - 이 프로그램은 실제 SCH-M480 기기가 아니라, PC에서 같은 계열 CPU(XScale)를
    흉내 내는 시험 환경에서 실제 실행 파일을 돌려 확인했습니다. 실제 기기에서
    문제가 있으면 위의 로그 파일을 보내 주시면 고칠 수 있습니다.
