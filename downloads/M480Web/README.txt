M480Web — SCH-M480(Windows Mobile 6.1)용 웹 브라우저
=====================================================

■ 무엇이 해결되나요?
기기에 들어있는 IE Mobile은 오래된 SSL/TLS 1.0만 지원하고 루트 인증서도
만료되어 요즘 https 사이트에 접속이 안 됩니다. M480Web은 자체 보안 엔진
(BearSSL, TLS 1.2)과 최신 루트 인증서 117개를 내장해서, 기기 OS와 상관없이
요즘 https 사이트에 직접 접속합니다.

■ 설치 방법 (둘 중 하나)
1) CAB 설치(권장): M480Web.cab 를 기기로 복사 → 파일 탐색기에서 탭 → 설치.
   시작 메뉴 > 프로그램에 "M480Web" 아이콘이 생깁니다.
2) 직접 복사: M480Web.exe 를 기기의 아무 폴더(예: \Program Files\M480Web)에
   복사해서 실행. 바로가기가 필요하면 M480Web.lnk 를
   \Windows\Start Menu\Programs 에 복사하세요(위 경로에 exe를 둔 경우).

■ 내 파일함 정리 (2026-11-27 업데이트)
- 내 파일함 첫 화면은 앱 목록만 보여 줍니다: '업데이트 있음' / '받은 앱' / '받지 않은 앱'으로 나뉘고,
  각 앱 아래에 상태(새 버전 있음·최신·일부 받음), 파일 수, 날짜가 나옵니다.
- 앱을 누르면 그 앱의 파일 목록과 [전체 받기](새 버전이면 [전체 업데이트 받기])가 나옵니다.
  '◀ 앱 목록' 또는 백스페이스로 돌아갑니다.

■ 나무위키 "Loading..." 빈 화면 (2026-11-26 3차 업데이트)
- 나무위키가 본문 없이 "Loading..."만 보내면, 자동으로 두 번 다시 받아 봅니다.
- 그래도 비어 있으면 그 문서의 원본 글(나무위키 원본 보기)을 받아 M480Web이 직접 글 화면으로
  바꿔서 보여 줍니다. 이때 맨 위에 '(원본 글로 표시합니다)'라고 나옵니다.
  표·틀·특수 서식 일부는 단순하게 보입니다.
- 둘 다 안 되면 빈 화면 대신 '다시 시도'와 '위키백과에서 찾기' 링크를 보여 줍니다.

■ 다크 모드·읽기 화면 (2026-11-26 2차 업데이트)
- 메뉴(≡) > '다크 모드 (어두운 화면)'를 켜면 검은 바탕에 밝은 글씨로 바뀝니다(설정 저장됨).
- 나무위키: 본문 링크의 밑줄을 없애 글이 덜 어지럽고, 각주 번호 [1]은 작게, 큰 제목 아래에는
  구분선을 넣었습니다. 좌우 여백도 조금 넓혔습니다. 이미지는 계속 받지 않습니다.
- 긴 문서를 화면에 그리는 계산을 빠르게 바꿔서 나무위키 큰 문서가 더 빨리 뜹니다.
- 검색 뒤 가끔 페이지를 못 불러오던 문제: 연결이 끊기거나 응답이 없으면 자동으로 두 번까지
  다시 시도합니다.

■ 스크롤 (2026-11-26 업데이트, M480Tube와 같은 방식)
- 화면 오른쪽에 끌 수 있는 스크롤 손잡이(▲▼ 표시)가 생겼습니다. 손잡이를 잡고 위아래로 끌면
  긴 페이지도 한 번에 원하는 위치로 갑니다. 손잡이 위아래 빈 곳을 누르면 그 위치로 바로 이동.
- 손가락으로 조금만 움직여도 스크롤로 인식해서, 스크롤하다 링크가 잘못 열리는 일이 줄었습니다.
- 미끄러지듯 움직이는 화면을 손가락으로 눌러 멈출 때는 링크가 열리지 않습니다.

■ 번역 (2026-11-24 업데이트)
- CNN 같은 외국어 페이지에서 메뉴(≡) > '한국어로 번역'을 누르면 글이 한국어로 바뀝니다.
  (Google 번역 사용, 페이지 길이에 따라 몇 초~수십 초. 아래 상태줄에 진행 표시)
- 번역 후 메뉴 > '원문 보기'를 누르면 원래 글로 돌아갑니다.
- 메뉴 > '외국어 페이지 자동 번역'에 체크하면 외국어 페이지를 열 때마다 자동으로 번역합니다.
- 문단 중간에 있던 작은 링크는 번역하면서 없어질 수 있습니다(제목 링크는 그대로 남음).
  링크를 눌러야 하면 '원문 보기'로 돌아가세요.

■ 키 조작 (2026-11-23 2차 업데이트)
- 종료(빨간) 버튼 위의 오른쪽 소프트키 = 메뉴(≡) 열기. 메뉴는 방향키와 확인 키로 고를 수 있습니다.
- 백스페이스(지우기) 키 = 뒤로 가기. (주소창이나 입력칸에서는 원래대로 글자를 지웁니다)
- 첫 화면의 검색창은 하나로 합쳤습니다. 단어를 넣고 [나무위키] 또는 [위키백과]를 누르세요.
  Enter 를 누르면 나무위키에서 찾습니다.

■ 나무위키 (2026-11-23 업데이트)
- 첫 화면 맨 위 검색창에 문서 이름을 넣고 [나무위키]를 누르면 그 문서가 바로 열립니다. 주소창에 단어만 쳐도 나무위키에서 찾습니다.
- 나무위키 페이지는 이미지를 받지 않고 글만 보여 줍니다. 사이트 메뉴, 편집·역사·토론 링크,
  광고 같은 군더더기는 숨기고, 맨 위에 다시 검색할 수 있는 검색창을 붙여 줍니다.
- 문서가 바로 없으면 '비슷한 나무위키 문서 찾기' 링크가 나옵니다.
- 각주 [1]을 누르면 아래로 이동하고, ◀(뒤로)를 누르면 읽던 자리로 돌아옵니다.
- 휴대폰 시계가 틀려서 생기던 보안 연결 오류(인증서 기간 오류)를 자동으로 보정합니다.

■ 사용법
- 상단: ◀ 뒤로 / ▶ 앞으로 / 새로고침(로딩 중엔 X = 중지) / 주소창 / ≡ 메뉴
- 주소창에 주소(예: ko.m.wikipedia.org) 또는 검색어를 입력하고 Enter.
  검색어는 나무위키에서 찾습니다.
- 화면을 손가락/스타일러스로 끌어서 스크롤(관성 스크롤 지원).
  방향키 위/아래 = 스크롤, 좌/우 = 한 페이지씩.
- 링크를 길게 누르면: 링크 열기 / 단순화 보기로 열기 / 주소 복사
- 입력칸을 누르면 키보드가 뜹니다. Enter = 전송.
- 홈 화면의 '바로가기' 목록은 직접 편집할 수 있습니다.
  홈의 [편집] 또는 메뉴 > '바로가기 편집'에서 이름·주소 수정, 순서 변경(위로/아래로),
  삭제, 새로 추가, 기본 목록으로 되돌리기가 가능합니다.
  보고 있는 페이지는 메뉴 > '바로가기에 추가'로 바로 넣을 수 있습니다.
- 메뉴(≡): 홈, 새로고침, 바로가기 추가/편집, 즐겨찾기 추가/목록, 방문 기록,
  단순화 보기(FrogFind), 이미지 표시 켜기/끄기, 글자 크기,
  브라우저 식별(피처폰/모바일/PC/IE Mobile), 페이지 정보, 쿠키 삭제, 종료

■ 내 파일함 (GitHub에서 바로 받기)
- 홈의 [내 파일함] 또는 메뉴 > '내 파일함'을 누르면 Claude가 GitHub 저장소(M480-APP)에
  올린 파일 목록이 나옵니다. 파일을 누르면 받고, [전체 받기]는 그 앱 파일을 한 번에 받습니다.
- 받은 파일은 메모리카드의 \M480-APP\앱이름\ 폴더에 저장됩니다(카드가 없으면 \My Documents\M480-APP).
- .cab 은 받은 뒤 바로 설치, .exe 는 바로 실행할 수 있습니다. 이미 받은 파일은 '받음',
  저장소에 새 버전이 올라오면 '새 버전 있음'으로 표시됩니다.
- 저장소가 '비공개'이면 GitHub 토큰이 필요합니다: 메뉴 > 내 파일함 > '파일함 설정'에서 입력하거나,
  토큰을 한 줄로 적은 github_token.txt 파일을 M480Web.exe 와 같은 폴더에 넣으세요.

■ 알아둘 점
- 자바스크립트는 지원하지 않습니다. 화면이 비거나 깨지는 사이트는
  메뉴 > "단순화 보기"(FrogFind)로 열면 글 위주로 읽을 수 있습니다.
- 기본 브라우저 식별은 "피처폰"입니다(가장 가벼운 페이지를 받음).
  사이트가 이상하면 메뉴 > 브라우저 식별에서 "모바일"로 바꿔 보세요.
- "인증서 유효기간 오류"가 나오면 기기의 날짜/시간이 맞는지 먼저 확인하세요.
  보안 경고 창에서 "예"를 누르면 그 사이트는 이번 실행 동안 허용됩니다.
- 지원 이미지: JPG, PNG, GIF(첫 장면), BMP. (WebP/SVG는 미지원)
- 데이터망(3G) 연결이 꺼져 있으면 자동으로 연결을 시도합니다.
- 바로가기/즐겨찾기/기록/쿠키/설정은 프로그램 폴더의 txt/ini 파일에 저장됩니다.
- 기기 화면 해상도(QVGA/WQVGA/VGA)에 맞춰 자동 확대됩니다.
