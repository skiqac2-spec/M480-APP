ABYSS PALADIN (어비스 팔라딘) - GBA 액션 RPG
=============================================

M480 게임 에뮬레이터(M480Emu)의 GBA로 실행합니다.

■ 넣는 법
  act1.gba ~ act5.gba 를 메모리 카드의 같은 폴더에 넣으세요.
  예) \Storage Card\Games\AbyssPaladin\
  M480Emu > [게임 고르기] 에서 act1.gba 부터 시작합니다.

■ 진행 방식
  액트마다 ROM이 따로 있습니다 (act1 -> act2 -> ... -> act5).
  액트를 깨면 패스워드가 나옵니다. 다음 액트 ROM을 켜고
  PASSWORD 를 골라 입력하면 레벨·장비가 이어집니다.
  액트 V를 깨면 나이트메어 -> 헬 난이도로 다시 act1부터 이어집니다.

■ 조작 (GBA 버튼)
  십자키   이동
  A        공격 / 치유사와 대화 / 대화 넘기기
  B        선택한 스킬 사용
  R        스킬 바꾸기 (강타 / 신성 화살 / 신성 해머)
  L        체력 물약
  SELECT   마나 물약
  START    캐릭터·스킬 창 / 대화 장면 건너뛰기
  (M480 키 배치는 M480Emu 사용 설명서 참고: A = L, B = K, L = U, R = O)
