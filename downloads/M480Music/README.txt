M480 뮤직 - SCH-M480(Windows Mobile 6.1)용 "안 깨지는" 음악 플레이어
=====================================================================

[왜 깨지나 / 어떻게 고쳤나]
- 기본 음악 재생기는 44.1kHz 원음을 그대로 내보내는데, M480의 오디오 경로(특히 이어폰
  앰프)가 요즘 음원처럼 꽉 찬 음량을 받으면 찌그러진다.
- 게임 소리가 멀쩡한 건 게임이 보통 22kHz/작은 음량으로 소리를 내기 때문.
- 이 플레이어는 음악을 직접 디코딩해서 게임과 같은 방식으로 출력한다.
    1) 22050Hz로 낮춰서 출력 (음질 "보통", 기본값)
    2) 출력 레벨을 60%로 낮춰 앰프에 여유를 줌 + 리미터로 순간 피크 억제
    3) 찌그러짐의 주원인인 초저음을 잘라냄 (이어폰 90Hz / 스피커 160Hz)
    4) 2초 분량 버퍼로 SD카드 읽기 지연에도 끊기지 않게 함
    5) 끊김이나 CPU 과부하가 감지되면 음질을 자동으로 한 단계씩 내림
       (보통 → 낮음(모노) → 최저(11kHz 모노))

[설치]
- M480Music.exe 를 SD카드 아무 곳에나 복사하고, 기기의 파일 탐색기에서 실행.
- 처음 실행 시 SD카드 전체와 \My Documents 에서 MP3/WAV를 찾아 목록을 만든다.
  (목록은 exe 옆 M480Music_list.txt 에 저장되어 다음부터는 바로 뜸)
- 음악을 새로 넣었으면 [새로고침].

[사용법] (2.3 - 블루투스 잡음 수정)
화면은 3개: 보관함 / 지금 재생 중 / 설정

■ 보관함 (첫 화면)
- 위쪽 [노래] [폴더] 로 보기 전환
  · 노래: 모든 곡을 한 목록으로
  · 폴더: SD카드의 폴더별로 묶어서 보기 → 폴더를 누르면 그 폴더 곡만 표시
    폴더 안에서 곡을 재생하면 '다음 곡'도 그 폴더 안에서만 넘어감 (앨범/플레이리스트처럼)
    왼쪽 위 < 또는 기기의 뒤로 키로 폴더 목록으로 돌아감
- 오른쪽 위 ▶ = 처음부터 재생, ⤨ = 셔플 (폴더 안이면 그 폴더만)
- 곡을 한 번 누르면 바로 재생. 손가락으로 끌어 올리면 목록이 미끄러지듯 스크롤
- 오른쪽 위 ••• = 설정
- 재생 중인 곡은 주황색 글씨 + 앨범아트 위 막대 애니메이션
- 맨 아래 미니 플레이어: 누르면 '지금 재생 중' 화면, 오른쪽 ∥/▶ 와 ▶▶ 버튼
■ 지금 재생 중
- 앨범아트: MP3 안에 들어 있는 그림 → 없으면 같은 폴더의 cover.jpg / folder.jpg
  (그림이 없으면 곡마다 다른 색 커버가 자동으로 그려짐)
- 제목/가수/앨범은 MP3 태그에서 읽음 (없으면 '가수 - 제목.mp3' 파일 이름에서)
- 진행 막대를 누르거나 끌어서 위치 이동
- 아래 동그란 버튼 4개: 재생 순서 / 음질 / 이어폰·스피커 / 소리 크기 (누를 때마다 바뀜)
- 왼쪽 위 ⌄ = 보관함으로
■ 블루투스 이어폰
- 블루투스 이어폰이 연결되면 자동으로 감지해서 44.1kHz 스테레오로 내보냄
  (블루투스는 22kHz·모노를 받으면 소리가 안 나는 경우가 있음)
- 재생 중에 블루투스를 연결/해제해도 1~2초 안에 새 장치로 소리가 옮겨감
- 6초 넘게 소리가 안 나가면 오디오 장치를 자동으로 다시 엶
- 블루투스 중에는 디코딩을 조금씩 나눠서 하고 우선순위를 낮춰
  블루투스 전송이 끊기지 않게 함 (삐-/지직 잡음 대책)
- 설정 → 출력 줄에 '끊김/부하' 숫자가 나옴. 잡음이 계속되면 이 숫자를 알려 주세요
- 그래도 블루투스에서 소리가 안 나면: 설정 → 블루투스 → "항상 켬"
  (유선 이어폰으로 돌아가면 "자동"으로 되돌리기)
■ 설정
- 음질, 출력 모드, 소리 크기, 재생 순서, 블루투스(자동/항상 켬/끔), 음악 목록 새로고침, 현재 출력 정보, 앱 종료
  → 이어폰에서 아직 깨지면 '소리 크기'를 "작게"로

■ 하드웨어 키
- ←/→ 이전·다음 곡, 가운데 버튼 재생·일시정지, ↑/↓ 목록 이동
- 왼쪽 소프트키 = 보관함 ↔ 지금 재생 중, 오른쪽 소프트키 = 설정
- 오른쪽 위 X 는 창만 숨김(음악 계속). 완전히 끄려면 설정 → 앱 종료.
- 화면을 꺼도 음악이 계속 나옴. 정지 후 다시 재생하면 지난번 위치부터 이어서.

[지원 형식]
- MP3 (CBR/VBR, MPEG1/2/2.5 Layer3), WAV (8/16/24bit PCM)
- WMA/AAC/OGG 는 미지원

[소스 구조]
- src/player.c  : 화면(직접 그리기), waveOut 출력, 자동 음질 조절, SD카드 검색
- src/art.c     : ID3 태그(제목/가수/앨범) + 앨범아트(stb_image로 JPEG/PNG 디코딩)
- res/          : 앱 아이콘 (make_icon.py 로 생성)
- test/preview/mock.py : PC에서 화면 미리보기 그림 만들기
- src/source.c  : MP3/WAV 디코더 래퍼 (ID3 건너뛰기, VBR 길이/탐색)
- src/dsp.c     : 저음컷 → 4차 LPF → 리샘플 → 레벨 → 리미터 (정수 연산만)
- src/helix/    : Helix 고정소수점 MP3 디코더 (RealNetworks RPSL 라이선스)
- 빌드: CeGCC(arm-mingw32ce) 로 make. 저장소 루트의 .github/workflows/m480music.yml 이
  자동으로 컴파일해서 M480Music.exe 를 만들어 준다(Actions 탭 → Artifacts).
