M480 홈 1.2 - 손가락으로 쓰기 쉬운 홈 화면
=========================================

윈도우 모바일 기본 '오늘' 화면과 시작 메뉴 대신 쓰는 홈 화면입니다.
큰 시계·배터리와 큰 앱 아이콘을 한 화면에 모아 두고, 누르면 바로 켜집니다.

[설치]
M480Web > 내 파일함 > M480Home > M480Home.cab 을 눌러 설치하면 끝입니다.
설치하면 다음부터 M480을 켤 때 자동으로 시작됩니다.
처음 켜면 지금까지 설치한 M480 앱(웹, 유튜브, 음악, 만화, 게임 에뮬,
피처폰 게임, 심연의 미궁, 통화)과 파일 탐색기·설정을 알아서 찾아 홈에 넣습니다.

[홈 화면]
- 아이콘 누르기: 앱 실행 (아래에 "○○ 여는 중…"이 뜨면 기다리면 됩니다.
  두 번 눌러도 두 번 켜지지 않습니다)
- 아이콘 옮기기: 아이콘을 꾹 눌러 '삑' 소리가 나면 손을 떼지 말고 끌어서
  원하는 칸에 놓으세요. 아무 칸에나 놓을 수 있고 빈칸을 남겨도 됩니다.
  다른 아이콘 위에 놓으면 두 아이콘 자리가 바뀝니다.
  화면 왼쪽/오른쪽 끝에 대고 있으면 옆 페이지로 넘어갑니다
  (마지막 페이지 오른쪽 끝에 대면 새 페이지가 생깁니다)
- 아이콘 꾹 눌렀다가 그냥 떼기: 홈에서 빼기 메뉴
- 좌우로 밀기: 다음 페이지 (아래 점이 페이지 표시)
- 빈칸 누르기 / '+ 앱 추가' 칸: 시작 메뉴의 모든 앱 목록이 나오고,
  누르는 앱마다 홈에 넣기/빼기가 됩니다 (누른 빈칸부터 채워짐). 끝나면 [다 했음]
- 맨 위: 시계, 날짜, 배터리(15% 아래는 빨간색, 충전 중은 초록색)
- 맨 위 오른쪽 Wi-Fi · 블루투스 단추
  · 켜져 있으면 파란색, 꺼져 있으면 회색. Wi-Fi는 인터넷이 연결되면 초록 점과 '연결됨'
  · 누르기: 켜기/끄기, 설정 열기 메뉴
  · 꾹 누르기: 설정 화면이 바로 열림
    (Wi-Fi: 무선 네트워크 고르기·비밀번호 입력, 블루투스: 기기 찾기·연결)
  · 켜기/끄기가 안 되는 기기면 "바꾸지 못했어요"가 뜹니다. 그때는 설정 열기로 해 주세요

[아래 단추 3개]
- 전체 앱: 시작 메뉴의 모든 프로그램을 가나다순 큰 목록으로.
           누르면 실행, 꾹 누르면 홈에 추가/빼기
- 실행 중: 지금 켜져 있는 앱 목록 (숫자는 켜진 앱 수)
           누르면 그 앱으로 전환, ✕ 로 닫기, [모두 닫기], 남은 메모리 표시
           (M480이 느려지면 여기서 앱을 닫아 주세요)
- 설정:    소리 크기, 화면 끄기, 배경화면, 아이콘 크기(보통 3×3 / 작게 4×3 / 크게 3×2),
           시계(24시간 / 오전·오후), 켤 때 자동 시작, 홈 앱 처음 상태로,
           앱 목록 다시 읽기, M480 홈 끝내기

[배경화면]
설정 > 배경화면
- 기본 배경 9가지(없음, 밤하늘, 노을, 숲, 바다, 보라, 분홍, 모래, 회색) 중 고르기
- 내 사진: My Documents와 메모리카드에 있는 JPG·PNG·BMP 사진이 목록에 나옵니다.
  누르면 화면에 꽉 차게(가운데 맞춤) 깔립니다.
  너무 큰 사진(420만 화소 넘음, 예: 요즘 폰 카메라 원본)은 못 엽니다.
  PC나 폰에서 320×320~1000×1000 정도로 줄여서 넣어 주세요.
- 글자 잘 보이게: 그대로 / 조금 어둡게 / 많이 어둡게 (밝은 사진이면 어둡게)

[오늘 화면 대신 쓰기]
기본으로 켜져 있습니다. 시작 버튼 > 오늘, 또는 홈 키로 '오늘' 화면이 나오면
M480 홈이 대신 앞으로 나옵니다. 원래 '오늘' 화면을 쓰고 싶으면
설정 > '오늘 화면 대신 M480 홈'을 끄세요.

[키]
방향키: 아이콘/줄 고르기 (처음 누르면 선택 테두리만 표시, 빈칸에서 확인 = 앱 추가)
가운데(확인): 실행        뒤로: 홈으로
왼쪽 소프트키: 전체 앱    오른쪽 소프트키: 실행 중
설정의 소리 크기 줄에서 ◀ ▶: 소리 줄이기/키우기

[파일]
설정과 홈 아이콘 순서는 M480Home.exe 옆의 M480Home.ini 에 저장됩니다.
이 파일을 지우면 처음 상태로 돌아갑니다.

[안 될 때]
- 앱이 안 열리고 "열 수 없어요"가 뜨면: 앱 폴더를 옮긴 경우입니다.
  그 아이콘을 꾹 눌러 빼고, '+ 앱 추가'에서 다시 넣어 주세요.
- 새로 설치한 앱이 안 보이면: 설정 > 앱 목록 다시 읽기
- 끝내고 싶으면: 설정 > M480 홈 끝내기
  (자동 시작도 끄려면 그 전에 '켤 때 자동으로 시작'을 끄세요)
