M480 만화 뷰어 1.0 - SCH-M480(Windows Mobile 6.1)용 만화/이미지 뷰어
======================================================================

사이트 주소를 넣으면 그 페이지의 만화 이미지만 골라서 화면에 맞춰 보여준다.

[특징]
- TLS 1.2 내장 (M480Web과 같은 엔진). 보안 인증서 오류(만료, 자체서명, 시계 틀림
  등)는 묻지 않고 무시하고 접속한다.
- 이미지 크기가 제각각이어도 자동으로 화면에 맞춤
  · 세로 스크롤 (기본): 모든 그림을 화면 폭에 맞춰 이어 붙임 - 웹툰/만화 모두
  · 한 장씩: 그림 한 장을 화면 안에 통째로 맞춰서 넘겨 보기 - 출판 만화용
  · 확대 150% / 200% (세로 스크롤에서, 좌우로 끌어서 이동)
- JPG / PNG / GIF / BMP / WebP 지원 (AVIF는 미지원)
- 아이콘·배너 같은 작은 그림(가로 160 미만 또는 세로 120 미만)은 자동으로 숨김
- 그림은 2개씩 동시에 받고, 보고 있는 근처만 풀어서 메모리를 아낌
  (수백 장짜리 회차도 열림)
- 다음 화 / 이전 화 자동 찾기 ("다음화", "다음 편", rel=next 등)
  못 찾으면 주소 끝의 숫자를 바꿔서 추정 (예: ...&no=1 → no=2)
- 최근 본 만화: 어디까지 봤는지 기억했다가 이어 보기
- 즐겨찾기, 페이지 링크 목록(목록 페이지에서 회차 고르기), 이미지 저장

[설치]
- M480Comic.cab 을 누르면 설치 (시작 > 프로그램 > M480 만화)
- 또는 M480Comic.exe 를 아무 폴더에 복사해서 바로 실행해도 된다.
- exe 옆에 cache 폴더(임시 그림), settings.ini, history.txt, bookmarks.txt 가 생긴다.

[사용법]
1. 위 주소창을 누르고 만화 페이지 주소 입력 → [이동]
   (http:// 는 생략 가능, 처음 실행 때 최근 본 만화가 있으면 목록이 먼저 뜸)
2. 화면 조작
   세로 스크롤 모드
   - 손가락으로 끌기: 위아래 스크롤 (튕기면 관성 스크롤)
   - 화면 위쪽 30% 누르기: 한 화면 위로 / 아래쪽 30% 누르기: 한 화면 아래로
   - 가운데 누르기: 전체 화면 켜기/끄기
   한 장씩 모드
   - 왼쪽 누르기 / 오른쪽 누르기: 이전 장 / 다음 장 (좌우로 밀어도 됨)
   - 가운데 누르기: 전체 화면 켜기/끄기
   - 실패한 그림(빨간 칸)을 누르면 다시 받기
   - 맨 끝에 [◀ 이전 화] [다음 화 ▶] 버튼
3. 키
   - 방향키 위/아래: 조금씩 스크롤 (한 장씩 모드는 넘기기)
   - 방향키 좌/우, 확인 키: 한 화면씩 넘기기
   - 지움(백스페이스): 전체 화면 해제 → 목록 닫기 → 뒤로
   - 오른쪽 소프트키: 메뉴 (화면 왼쪽 위 ≡ 버튼도 같음)

[메뉴]
- 다음 화 / 이전 화 / 뒤로 / 새로고침 / 주소 입력
- 최근 본 만화: 누르면 마지막으로 본 위치부터 이어 보기
  (목록에서 메뉴 > 선택한 항목 삭제)
- 즐겨찾기 > 즐겨찾기 목록 / 지금 페이지 추가
- 페이지 링크 목록: 그 페이지의 링크 전부 → 회차 목록 페이지에서 회차 선택할 때
- 보기 방식 / 확대: 세로 스크롤 / 한 장씩, 확대 100·150·200%, 작은 이미지도 표시
- 전체 화면, 건너뛰기(맨 처음/맨 끝)
- 기타 > 지금 이미지 저장 (\My Documents\M480Comic 에 원본 저장)
       > 사이트에 보일 기기 (모바일/PC/아이폰 - 사이트에 따라 모바일이 그림이 더 잘 나옴)
       > 쿠키 삭제 / 페이지 정보

[안 되는 경우]
- 그림을 자바스크립트로 나중에 불러오는 사이트는 그림을 못 찾을 수 있다.
  (스크립트 안에 적힌 그림 주소까지는 찾아봄)
  → 메뉴 > 사이트에 보일 기기 를 PC 또는 아이폰으로 바꾸고 새로고침 해 볼 것
- Cloudflare 같은 "사람 확인" 화면이 뜨는 사이트, 로그인이 필요한 사이트는 안 됨
- 이미지 한 장이 420만 화소(예: 700 x 6000)를 넘으면 "너무 큰 이미지"로 표시
- TLS 1.3 만 받는 서버는 접속이 안 될 수 있다 (거의 없음)
