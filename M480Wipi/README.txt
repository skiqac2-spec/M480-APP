M480 WIPI - SCH-M480(Windows Mobile 6.1)용 피처폰 게임 에뮬레이터
==================================================================

예전 SKT / KTF / LG텔레콤 휴대폰의 WIPI·SK-VM 자바 게임을 SCH-M480에서
실행합니다. 게임을 실행할 때 통신사를 고를 수 있고, 휴대폰 키를 M480 키에
마음대로 연결(키 매핑)할 수 있습니다.

1. 설치
-------
- M480Wipi.cab 을 누르면 설치됩니다 (시작 > 프로그램 > M480 WIPI).
- 설치 없이 M480Wipi.exe 만 복사해서 실행해도 됩니다.

2. 게임 넣기
------------
게임 파일(.jar 또는 .zip)을 아래 폴더 중 하나에 넣으세요. 하위 폴더도 찾습니다.
  \Storage Card\WIPI\
  \Storage Card\Games\WIPI\
  \My Documents\WIPI\
  (설치폴더)\games\

통신사별 파일 모양
  SKT : 게임.jar + 게임.msd (같은 이름으로 나란히)
  KTF : zip 안에 jar + __adf__ (또는 폴더째로)
  LGT : zip 안에 jar + app_info (또는 폴더째로)
  일반 J2ME(MIDP) : .jar (+ .jad)

3. 실행 (통신사 선택)
---------------------
목록에서 게임을 고르고 확인 키 → "통신사 선택" 창이 열립니다.
- SKT / KTF / LGT 중 하나를 고릅니다. 파일 모양으로 자동 감지한 통신사에
  "자동감지" 표시가 붙어 있습니다. 고른 통신사는 게임별로 기억됩니다.
- 통신사에 따라 바뀌는 것: 게임에 전달되는 키 코드(SKT의 SK-VM 방식 /
  KTF·LGT 방식), 통신사 시스템 속성 등.
  게임에서 방향키가 안 먹거나 이상하면 다른 통신사로 실행해 보세요.
- "화면 크기"는 보통 자동(240x320)으로 두면 됩니다. 오래된 게임은
  176x208, 128x160 등을 골라 보세요.
- 왼쪽 소프트키(시작)로 바로 시작, 오른쪽 소프트키는 취소.

4. 키 매핑
----------
목록 화면 왼쪽 소프트키(메뉴) > "키 설정", 또는 게임 중 종료키(빨간 버튼)
> "키 설정".
- 휴대폰 키(0~9, *, #, 방향키, 확인, 소프트키, 지움, 통화...)를 고르고
  확인 → M480에서 누를 키를 누르면 연결됩니다. 한 휴대폰 키에 여러 개를
  연결할 수 있습니다.
- Back(지움): 그 줄의 연결 해제 / 왼쪽 소프트키: 기본값 / 오른쪽: 완료
- 게임 중에 열면 좌우 방향키로 "이 게임만 / 모든 게임" 적용 범위를 바꿀
  수 있습니다.

기본 키
  방향키·OK = 방향키·확인     왼쪽/오른쪽 소프트키 = 소프트키
  Back = 지움(CLR)            통화 버튼 = 통화
  숫자: W E R = 1 2 3,  S D F = 4 5 6,  X C V = 7 8 9
        스페이스 = 0,  Z = *,  B = #   (숫자 키를 직접 눌러도 됩니다)

화면 옆 터치 버튼: 소프트키, 지움, *, #, 메뉴, 확인, 0, 5, 통화
게임 화면을 터치하면 터치(포인터) 이벤트로 전달됩니다.

5. 게임 중 메뉴 (종료키 또는 화면 옆 '메뉴')
-------------------------------------------
계속하기 / 키 설정 / 소리 켜기·끄기 / 화면(비율 맞춤·꽉 채움) / 게임 종료

6. 저장
-------
게임 저장 데이터(RMS, WIPI DataBase, 파일)는 (설치폴더)\save\게임ID\ 에
저장됩니다.

7. 지원 범위
------------
지원: 자바(.class)로 된 게임
  - WIPI 자바 (org.kwis.msp.*: Jlet, Card, Graphics, Image, Clip, DataBase...)
  - SK-VM / MIDP 1.0·2.0 (Canvas, GameCanvas, Sprite, TiledLayer, RMS,
    Form/List/Alert, Media Player), com.skt.m 확장 일부, Nokia FullCanvas
  - 이미지: PNG, GIF, BMP, JPEG(기본형)
  - 소리: MMF(SMAF, 벨소리 형식), MIDI, WAV - 간이 신디사이저로 재생
지원 안 됨(아직):
  - KTF·LGT의 "네이티브" 게임 (jar 안에 client.bin / binary.mod 만 있고
    .class 가 없는 게임, WIPI-C). 목록에 주황색 "지원 안 됨"으로 표시됩니다.
  - 네트워크 접속, 문자 보내기, 3D(com.skt.m3d)

8. 문제 해결
------------
- 실행 기록: (설치폴더)\m480wipi_log.txt  (오류 내용이 남습니다)
- 게임이 안 뜨면 다른 통신사/화면 크기로 다시 실행해 보세요.
